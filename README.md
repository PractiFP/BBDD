# PractiFP - Base de datos

Este repositorio contiene el diseño y la implementación de la base de datos de PractiFP, una plataforma para encontrar prácticas profesionales.

## Estructura

- `modelos/modelo-er.mmd`: diagrama entidad-relación.
- `modelos/modelo-relacional.mmd`: representación del modelo relacional.
- `sql/schema.sql`: script SQL para crear las tablas y sus restricciones.
- `sql/datos-prueba.sql`: datos de prueba para el desarrollo.

## Tecnologías

- MariaDB
- SQL
- Mermaid

## Modelos

Los diagramas se mantienen en formato Mermaid para facilitar su edición y actualización.
